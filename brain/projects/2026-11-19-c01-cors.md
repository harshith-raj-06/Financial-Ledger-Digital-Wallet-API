## Design

- Reuse FastAPI's CORSMiddleware rather than implementing CORS headers manually.
- Allow one explicit FRONTEND_ORIGIN; default to http://localhost:5173.
- Reject wildcard, opaque null, credentials, paths and invalid ports at startup.
- Limit preflights to GET/POST and the documented API headers.
- Expose replay/request-ID response headers for later features; do not generate
  them here. No cookies, auth implementation or financial routes are added.
- Keep CLI requests working and preserve safe health-error responses.
